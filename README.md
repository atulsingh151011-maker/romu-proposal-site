# README

This is a playful, animated romantic proposal website themed around a cute cat and the name Romu.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project contents

- `index.html` — page structure and content
- `style.css` — the playful cat-themed design and animations
- `script.js` — interactive heart effects and cute melody

## About

The website is a single-page romantic confession with:

- a dreamy pastel layout
- cute cat illustration
- animated floating hearts
- a love note for Romu
- a final heartfelt proposal moment with a tiny generated melody

If you'd like, you can personalize the message further with your own names, inside jokes, or a special date.
